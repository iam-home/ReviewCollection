비로그인 유저
    별점 / 리뷰 가능
    db에 저장 안함. 로컬스토리지로 할 거임 -> 나중에 로그인을 하면 로컬스토리지에 있던 것들을 db로 넣어야 되는데 어케함 그거
    db에 안 넣어도 되는 데이터 다룰 거면 허용해줘도 됨

로그인 유저
    별점 / 리뷰 / 친구추가
    데이터를 db에 넣을 거임. 익명은 좀 생각해봐야됨.


평균 같은 거는 api에 있지 않을까 싶음. 혹시 없으면 내 유저들 데려다가 해야되는데 그만큼 유저가 있을지도 모르겠고, api에 없으면 비로그인 친구들한테는 평균을 못 보여줌. 큰 문제는 아닌 거 같기는 한데 그래도 평균 별점 보여주는 게 낫지 않나 싶음


로그인 애들도 로컬스토리지를 써서 검색결과 저장하거나, 와이파이 끊기는 거 대처하거나 그런 거 생각해보셈

설정도 있으면 좋지 않을까. 테마라든가, 뭐 비율이나 글자 크기나, 다크모드는 있으면 좋을텐데. 나중에 업데이트 해도 됨
